RoomDiscovery.kt advertises _sudokut._tcp. with up to 20 characters of host name, port, wire version, session ID and locked flag; nearby LAN observers may see advertised room identity even if not joined. Wi-Fi discovery includes networks without validated internet; guest socket uses Wi-Fi network socket factory. HostServer uses ServerSocket(0), not explicitly bound to a Wi-Fi address; review interface exposure before release. Protocol.kt uses plaintext length-prefixed UTF-8 JSON over TCP (131072-byte frame cap), including names, room code, rejoin token, appearance, state, operations, chat, timestamps and history. Room code is not encryption; avoid claims of confidentiality or authenticated trusted peers. HostServer keeps bounded chat history and applies chat cleaning/rate limits; reconnect welcome includes history. Verify actual retention, exit/reset, persistence, block/report/parental controls and optional code defaults before audience classification. Do not infer child compliance from message length limits.
